**技术焦点**：仿真物理保真度与渲染管线成熟度双线并进。柔性体（flex）仿真深化，新增弯曲力与刚体模态投影，显著提升布料、软体等可变形物体仿真的真实性与稳定性。渲染层从实验性代码向公共API演进，新增创建/销毁渲染对象、离屏渲染等标准接口，为数字孪生与定制化渲染平台奠定基础。
