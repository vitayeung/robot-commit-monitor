# RLinf/RLinf Release Roadmap

- 仓库: `RLinf/RLinf`
- 统计窗口: 最近一年
- 最新版本: v0.2 (2026-03-26 23:06:12 CST)
- 纳入统计的最早版本: v0.1 (2025-12-17 20:01:25 CST)
- 版本概况: 最近一年共 2 个版本，其中正式版 2 个、预发布版 0 个
- 详细证据索引: `RLinf_RLinf_release_roadmap_reference.md`

## 核心判断

- **RLinf 在 v0.2 中完成了从“仿真验证”到“真实世界部署”的关键跨越。** v0.1 主要验证了在 ManiSkill、LIBERO 等仿真环境中的强化学习训练能力，而 v0.2 正式支持 XSquare Turtle2 双臂机器人和 Franka 机械臂的真机强化学习，并提供了配套的数据采集、策略训练和部署流程。这意味着产品已具备从实验室仿真到实际机器人产线或科研场景的落地能力。

- **多智能体强化学习（Multi-Agent RL）成为 v0.2 的第二大核心能力支柱。** 产品原生支持多智能体训练框架，并复现了 WideSeek-R1 等复杂解决方案。这标志着 RLinf 从单智能体场景正式扩展至多智能体协作与竞争场景，覆盖了更广泛的 AI 研究与应用需求。

- **世界模型（World Model）作为仿真器被正式引入训练流程。** v0.2 支持 OpenSora、Wan、WoVR 等生成式世界模型作为强化学习的仿真环境，实现了“Real2Sim2Real”闭环训练。这一能力显著降低了真实机器人数据采集成本，并提升了策略的泛化性和安全性。

- **训练基础设施和生态兼容性大幅增强，但迁移成本需关注。** v0.2 引入了异步训练、CUDA Graph、torch.compile、FSDP 优化等性能提升手段，并新增了对 NPU、AMD GPU、非 Debian 系统的支持。然而，由于涉及大量配置重构和接口调整（如 FSDP 精度处理重构、数据层接口重写），从 v0.1 升级可能需要适配工作。

## 产品演进主线

- **从仿真到真实世界的跨越：** v0.1 聚焦于在 ManiSkill、LIBERO、MetaWorld、CALVIN 等仿真器中验证 VLA 模型的强化学习训练，并取得了最高 99% 的成功率。v0.2 则直接支持 XSquare Turtle2 和 Franka 两款真实机器人平台，提供了从数据采集、SAC/PPO 训练到真机部署的完整流程。这一演进使产品从研究验证工具转变为可落地的机器人强化学习平台。

- **多智能体与推理能力的原生支持：** v0.1 已支持单智能体的推理和编码智能体任务，并在 AIME 等基准上取得领先结果。v0.2 在此基础上原生支持多智能体训练框架，统一了数据接口，并复现了 WideSeek-R1 等复杂多智能体方案。同时，PPO 算法被扩展至推理任务场景，进一步巩固了产品在 Agentic RL 方向的能力。

- **世界模型驱动的 Sim-to-Real 闭环：** v0.2 引入了基于 OpenSora、Wan、WoVR 等生成式世界模型的训练范式。这些世界模型可以“想象”轨迹并作为仿真器提供奖励信号，使策略可以在不接触真实机器人的情况下进行优化。结合 GSEnv（ManiSkill-GS）实现的 Real2Sim2Real 流程，产品为数据稀缺场景提供了可行的解决方案。

- **训练效率与生态兼容性的系统性提升：** v0.2 在训练基础设施上进行了大量优化，包括异步 PPO、CUDA Graph、torch.compile、环境卸载、FSDP 路径优化等，旨在提升高吞吐训练效率。同时，产品扩展了对 NPU、AMD GPU、非 Debian 系统的支持，并新增了 FUSCO 通信库以加速 MoE 训练，体现了向更广泛硬件生态兼容的意图。

## 版本演进解读

### v0.2（2026-03-26）

- **真实世界机器人强化学习正式支持。** 新增 XSquare Turtle2 双臂机器人和 Franka 机械臂的真机训练流程，支持 SAC、Cross-Q、RLPD 等算法，并提供从数据采集到策略部署的完整文档和配置。用户可直接在真实机器人上训练基于 ResNet 的 CNN 策略，完成按钮按压、插块插入等任务。

- **多智能体强化学习原生支持。** 引入可扩展的多智能体 RL 算法和统一数据接口，显著降低多智能体任务的开发门槛。已复现 WideSeek-R1 等复杂解决方案，并支持 PPO 在推理任务中的应用。同时新增 rStar2 和 Search-R1 的智能体 RL 训练示例。

- **世界模型作为仿真器加入训练流程。** 支持 OpenSora、Wan、WoVR 三种世界模型，可生成“想象”轨迹用于 VLA 策略的强化学习优化。结合 GSEnv 实现 Real2Sim2Real 闭环训练，并支持基于世界模型的 Sim-Real 协同训练（Co-Training）。这为数据稀缺场景提供了低成本策略优化路径。

- **训练基础设施重大升级。** 异步 PPO 成为一等公民，支持高吞吐训练。新增 CUDA Graph、torch.compile、环境卸载、FSDP 路径优化等运行时性能优化。数据层重构了回放缓冲区接口，支持预加载、更新和检查点处理。FSDP 精度处理重构为仅支持 fp16/bf16，但保持向后兼容。

- **模型与算法生态大幅扩展。** 新增对 Dexbotic 模型、openpi 模型族（RoboTwin 2.0）、CALVIN 和 RoboCasa 基准、DSRL（Diffusion Steering via RL）、SAC-Flow 等算法的支持。VLM 监督微调（SFT）功能上线，在 Robo2VLM 数据集上达到约 95% 的复现精度。Megatron 后端新增 FUSCO 通信库支持，提升 MoE 训练性能。

- **兼容性与部署优化。** 支持 NPU（昇腾）、AMD GPU、非 Debian 系统。新增 PyPI 安装方式，提供国内镜像加速选项。Docker 镜像体系完善，覆盖多种训练场景。文档全面重组，新增 FAQ、出版物页面和 AGENTS.md。

- **迁移注意：** 提供资料未明确描述 v0.1 到 v0.2 的破坏性变更。但 FSDP 精度处理重构、数据层接口重写、以及大量配置文件的调整，建议用户参考文档进行配置迁移和验证。

### v0.1（2025-12-17）

- **首个公开版本，奠定产品基础架构。** 发布 Worker、Scheduler、Channel 三层系统设计，支持 GPU/NPU/CPU 异构资源管理和自动调度。Channel 提供自适应高性能通信，自动选择零拷贝 cudaIPC、NCCL、Gloo 等后端。这一架构为后续扩展提供了灵活的组件化基础。

- **仿真环境中的 VLA 强化学习验证。** 支持 ManiSkill、LIBERO、MetaWorld、CALVIN、BEHAVIOR-1K、IsaacLab 六大仿真器，以及 OpenVLA、OpenVLA-OFT、π₀、π₀.₅、GR00T 五种 VLA 模型。在 ManiSkill 等基准上达到最高 99% 的成功率，训练吞吐量相比现有框架提升最高 143.4%。

- **推理与智能体 RL 能力。** 在 1.5B 和 7B 模型上，于 AIME 24/25 和 GPQA-Diamond 基准取得领先结果。支持 GRPO、PPO、DAPO、REINFORCE++ 四种算法。引入首个开源 1.5B 在线 RL 编码智能体，代码补全准确率提升 50% 以上，超越 32B 规模模型。

- **系统级效率优化。** 支持 Megatron 和 FSDP 训练后端，以及 SGLang、vLLM、HuggingFace 推理后端。自动调度和动态组件扩缩容能力带来 20%-40%+ 的效率提升。统一算法、环境和模型接口设计为后续扩展奠定基础。

## 采用与规划提示

- **v0.2 是真实世界部署的起点，建议有真机需求的团队优先评估。** 如果您的业务涉及 XSquare Turtle2 或 Franka 机械臂的强化学习训练，v0.2 提供了从数据采集到策略部署的完整流程。对于仅需仿真验证的场景，v0.1 已足够成熟，但 v0.2 的世界模型和异步训练能力可显著提升训练效率。

- **多智能体 RL 是差异化优势，但生态尚在早期。** 原生多智能体支持是 RLinf 区别于其他框架的核心能力之一，但目前仅复现了 WideSeek-R1 等少数方案。如果您的团队正在探索多智能体协作或竞争场景，建议从 v0.2 开始构建，并关注后续版本对更多算法和基准的支持。

- **世界模型训练范式值得关注，但需评估计算成本。** 基于 OpenSora 等生成式世界模型的训练方法在数据效率和安全性上有显著优势，但世界模型本身的训练和推理需要额外的计算资源。建议在资源充足的前提下，优先在 LIBERO 等已有世界模型支持的基准上验证效果。

- **生态兼容性持续扩展，但硬件适配需验证。** v0.2 新增了对 NPU、AMD GPU 的支持，并提供了国内镜像加速。如果您的集群使用非 NVIDIA 硬件，建议在 v0.2 上进行充分的功能验证。同时，FUSCO 通信库的引入表明产品正在向大规模 MoE 训练场景延伸，适合有大模型训练需求的团队关注。
