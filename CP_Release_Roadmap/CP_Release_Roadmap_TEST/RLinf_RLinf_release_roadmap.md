# RLinf/RLinf Release Roadmap

- 仓库: `RLinf/RLinf`
- 统计窗口: 最近一年
- 最新版本: v0.3 (2026-07-15 21:33:16 CST)
- 纳入统计的最早版本: v0.1 (2025-12-17 20:01:25 CST)
- 版本概况: 最近一年共 3 个版本，其中正式版 3 个、预发布版 0 个
- 详细证据索引: `RLinf_RLinf_release_roadmap_reference.md`

## 核心判断

- **RLinf 从 v0.1 到 v0.3 完成了从“可扩展的强化学习后训练框架”到“端到端真实世界训练基础设施”的完整闭环。** v0.1 验证了框架在仿真环境中的基础能力与性能优势；v0.2 大幅扩展了真实机器人平台支持、世界模型和多智能体训练；v0.3 则打通了从数据采集、监督微调（SFT）、强化学习到部署的全流程，并新增了 6 个具身模型和 5 个仿真器，产品成熟度显著提升。

- **v0.3 的核心战略方向是“端到端真实世界训练流水线”与“模型生态的深度扩展”。** 新增了 Franka 双臂、灵巧手、GELLO 遥操作等真实机器人工作流，并引入了 DreamZero（从 WAN2.1/2.2 视频生成世界模型微调的 VLA 策略）、GR00T-N1.6/N1.7、StarVLA、ABot-M0、LingBot-VLA 等新模型。同时，SFT 被明确定位为具身强化学习的标准冷启动步骤，提供了完整的全量和 LoRA 微调配方。

- **v0.3 在系统层面进一步优化了训练效率。** DreamZero SFT 通过 FSDP2 和 CUDA Graph 实现了近 4 倍的吞吐量提升。新增的仿真器（如 RoboCasa 等）和端到端测试工作流（embodied-e2e-tests.yml 大幅扩展）表明框架的稳定性和可复现性得到了严格验证。

- **v0.2 和 v0.1 的结论保持不变。** v0.2 奠定了真实世界强化学习和多智能体训练的基础，v0.1 则提供了坚实的架构底座。v0.3 在此基础上完成了从研究验证到生产级部署的完整闭环。

## 产品演进主线

- **从仿真验证到真实世界部署的跨越，并在 v0.3 中完成端到端闭环。** v0.1 主要聚焦于仿真环境中的强化学习训练；v0.2 引入了 XSquare Turtle2 和 Franka 真实机器人支持以及世界模型作为仿真器；v0.3 则进一步扩展了 Franka 双臂、灵巧手、GELLO 遥操作等真实机器人工作流，并新增了数据采集、SFT、部署等完整流水线。这一演进意味着 RLinf 已从研究验证阶段进入了可复现的生产级部署阶段。

- **从单智能体到多智能体强化学习的扩展，并在 v0.3 中深化了模型生态。** v0.1 主要支持单智能体算法；v0.2 引入了原生多智能体训练支持；v0.3 则新增了 6 个具身模型（DreamZero、GR00T-N1.6/N1.7、StarVLA、ABot-M0、LingBot-VLA）和 5 个仿真器，模型生态从 VLA 扩展到了世界模型驱动的 VLA 策略（DreamZero），覆盖了更广泛的研究和应用需求。

- **训练基础设施从“可用”到“高效”再到“可复现”的升级。** v0.1 具备自动调度和多后端支持；v0.2 增加了异步训练、CUDA Graph 等性能优化；v0.3 则通过 FSDP2 和 CUDA Graph 实现了 DreamZero SFT 近 4 倍的吞吐量提升，并通过大幅扩展的端到端测试工作流（embodied-e2e-tests.yml 新增 655 行）确保了所有示例的正确性和可复现性。

- **SFT 被明确定位为具身强化学习的标准前置步骤。** v0.3 新增了专门的 SFT 索引页面，将 SFT 定义为“具身强化学习的标准冷启动步骤”，并提供了完整的全量和 LoRA 微调配方。这意味着 RLinf 的产品设计从单一的强化学习框架演进为包含 SFT、RL、部署的完整训练流水线。

## 版本演进解读

### v0.3（2026-07-15）

- **端到端真实世界训练流水线正式完成。** 新增 Franka 双臂（dual_franka）、灵巧手（dexhand）、GELLO 遥操作等真实机器人工作流，覆盖从数据采集、SFT、强化学习到部署的完整流程。新增了专门的真实机器人索引页面（real_world_index.rst），按机器人平台分类提供配置路径。这意味着用户可以在单一框架内完成从硬件设置到策略部署的全流程。

- **模型生态大幅扩展，新增 6 个具身模型。** 包括 DreamZero（从 WAN2.1/2.2 视频生成世界模型微调的 VLA 策略，通过 FSDP2/CUDA Graph 实现近 4 倍吞吐量提升）、GR00T-N1.6/N1.7、StarVLA（LIBERO 上的 GRPO 微调）、ABot-M0、LingBot-VLA（RoboTwin 环境 SFT/RL）和 Dexbotic DM0（LIBERO 上的 PPO 微调）。同时新增了 5 个仿真器，进一步拓宽了仿真 RL 的场景覆盖。

- **SFT 被明确定位为具身强化学习的标准前置步骤。** 新增了专门的 SFT 索引页面，提供 OpenPI、DreamZero、VLM 等模型的完整全量和 LoRA 微调配方。SFT 检查点被描述为“能显著缩短 RL 探索时间并提升最终策略效果”。这意味着用户现在可以遵循“SFT → RL → 部署”的标准流水线进行开发。

- **兼容性与迁移说明。** 提供的来源未明确描述破坏性变更。新增的 Docker 镜像标签（如 agentic-rlinf0.3-maniskill_libero）与 v0.2 的镜像标签格式一致，建议用户升级到 v0.3 的 Docker 镜像以获取最新功能。文档结构进行了重组，新增了 SFT 和真实机器人索引页面。

### v0.2（2026-03-26）

- **真实世界强化学习成为核心能力。** 新增对 XSquare Turtle2 双臂机器人和 Franka 机械臂的真实机器人训练支持，支持 SAC、Cross-Q、RLPD 等算法，并提供完整的 Docker 镜像和安装指南。这意味着用户可以直接在真实机器人上运行强化学习训练，而不仅限于仿真环境。

- **世界模型作为仿真器引入。** 支持 OpenSora、Wan、WoVR 三种世界模型作为强化学习训练的仿真环境，能够生成“想象”的轨迹来优化 VLA 策略。这为 Sim-to-Real 和 Real2Sim2Real 训练提供了新的技术路径，降低了真实机器人训练的成本和风险。

- **原生多智能体训练支持。** 引入了可扩展的多智能体强化学习算法和统一数据接口，能够复现 WideSeek-R1 等复杂多智能体解决方案。同时，PPO 扩展到了推理任务场景（Reasoning PPO），并支持了 rStar2 和 Search-R1 等智能体强化学习方案。

- **训练基础设施全面升级。** 新增原生异步训练（Async PPO）支持，引入 CUDA Graph、torch.compile、环境卸载、FSDP 路径优化等性能优化。重构了数据收集和回放缓冲区架构，增强了缓冲区预加载、更新和检查点处理能力。这些改进显著提升了高吞吐训练效率。

- **模型与算法生态大幅扩展。** 新增对 Dexbotic 模型、openpi 模型族、RoboTwin 2.0 的支持，引入 SAC-Flow、DSRL、VLM SFT 等新算法。新增 CALVIN、RoboCasa 等基准测试支持，并验证了 Robo2VLM 数据集的 SFT 效果（约 95% 的复现准确率）。同时，Megatron 后端新增 FUSCO 通信库支持，提升了 MoE 训练和推理的 All-to-All 通信性能。

- **兼容性与迁移说明。** 提供的来源未明确描述破坏性变更。FSDP 精度处理被重构为仅支持 fp16 和 bf16，但保留了向后兼容性。文档被重新组织，示例被分类为具身、智能体和系统级优化三类。

### v0.1（2025-12-17）

- **首个公开版本，奠定了框架的架构基础。** 引入了 Worker/Scheduler/Channel 三层系统抽象，支持 GPU、NPU、CPU 异构资源管理，以及自动 GPU 资源调度和动态组件扩缩容。Channel 提供了自适应高性能通信，自动选择最优通信后端（零拷贝 cudaIPC、NCCL、Gloo 等）。

- **在具身强化学习场景验证了显著性能优势。** 支持 ManiSkill、LIBERO、MetaWorld、CALVIN、IsaacLab、BEHAVIOR-1K 等主流仿真器，以及 OpenVLA、π₀、GR00T 等 VLA 模型。在多个基准测试上达到最高 99% 的成功率，训练吞吐量比现有框架最高提升 143.4%（2.434 倍），并支持灵活分配、解耦和混合执行模式。

- **在推理和智能体场景展示了强大能力。** 使用 1.5B 和 7B 模型在 AIME 24、AIME 25、GPQA-Diamond 等基准测试上达到最先进结果。通过流水线并行（20%+ 加速）和自动调度（30%+ 加速）显著提升效率。引入了首个开源 1.5B 在线强化学习智能体，代码补全准确率提升 50%+，超越 32B 规模模型。

- **支持多种算法和训练后端。** 支持 GRPO、PPO、DAPO、REINFORCE++ 等算法，以及 Megatron、FSDP 训练后端和 SGLang、vLLM、HuggingFace 推理后端。提供了统一的算法、环境和模型接口。

## 采用与规划提示

- **v0.3 适合需要完整端到端真实世界训练流水线的团队采用。** 新增的 Franka 双臂、灵巧手、GELLO 遥操作等真实机器人工作流，以及从数据采集到部署的完整流程，使 RLinf 成为真实世界强化学习研究的首选框架。建议团队评估自身硬件兼容性（特别是 Franka 机械臂和 GELLO 设备），并参考官方 Docker 镜像进行部署。

- **SFT 流水线的完善降低了强化学习冷启动的门槛。** v0.3 将 SFT 明确定位为强化学习的前置步骤，并提供了完整的全量和 LoRA 微调配方。建议团队在开始强化学习训练前，先使用 SFT 获得一个良好的初始检查点，以显著缩短 RL 探索时间并提升最终策略效果。

- **DreamZero 等新模型为世界模型驱动的 VLA 策略提供了新的技术路径。** DreamZero 从 WAN2.1/2.2 视频生成世界模型微调 VLA 策略，并通过 FSDP2/CUDA Graph 实现了近 4 倍的吞吐量提升。建议关注世界模型作为仿真器和策略初始化来源的潜力，评估其在自身场景中的适用性。

- **端到端测试工作流的大幅扩展表明框架的稳定性和可复现性得到了严格验证。** v0.3 的发布说明明确提到“所有支持的示例都经过了严格验证，确保正确性和可复现性”。建议团队在采用新版本时，优先使用官方提供的 Docker 镜像和示例配置，以降低部署风险。
