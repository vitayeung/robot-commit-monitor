- 纳入统计的最早版本: v0.1 (2025-12-17 20:01:25 CST)
- 版本概况: 最近一年共 2 个版本，其中正式版 2 个、预发布版 0 个
- 详细证据索引: `RLinf_RLinf_release_roadmap_reference.md`

## 核心判断

- **RLinf 从 v0.1 到 v0.2 完成了从“可用的强化学习框架”到“面向真实世界与多智能体场景的生产级平台”的跨越。** v0.1 主要验证了框架在仿真环境（ManiSkill、LIBERO 等）和推理任务上的基础能力，而 v0.2 的核心突破在于支持真实机器人（XSquare Turtle2、Franka Arm）的强化学习训练，并引入了原生多智能体支持。这表明产品路线图已从技术验证阶段进入场景落地阶段。

- **v0.2 大幅扩展了生态覆盖，新增了世界模型作为仿真器、更多机器人基准测试和算法，显著降低了用户进入门槛。** 新增的 OpenSora、Wan、WoVR 等世界模型允许用户在“想象”的轨迹上进行策略优化，无需真实机器人即可进行闭环训练。同时，RoboTwin 2.0、CALVIN、RoboCasa 等新基准测试的加入，以及 SAC-Flow、DSRL 等新算法的支持，使框架的适用场景从单一仿真扩展到 sim-to-real 和 co-training 等复杂工作流。

- **训练基础设施的升级是 v0.2 的另一大亮点，原生异步训练和多项性能优化直接提升了高吞吐量场景下的效率。** 异步 PPO 作为一等公民能力被引入，配合 CUDA Graph、torch.compile、环境卸载等运行时优化，旨在解决大规模训练中的吞吐瓶颈。对于追求训练效率的团队，这些改进是显著的加分项。

- **v0.1 和 v0.2 均未明确提及破坏性变更或迁移指南，但 v0.2 的改动量巨大，用户需注意配置和接口的潜在不兼容。** 提供的源材料未明确描述破坏性变更，但 v0.2 重构了数据层、FSDP 精度处理、以及部分组件接口（如 EnvManager 被移除），建议用户在升级前仔细阅读文档中的示例配置和 API 变更。

## 产品演进主线

- **从仿真验证到真实世界部署：** v0.1 专注于在 ManiSkill、LIBERO 等仿真环境中验证 VLA 模型的强化学习训练，并宣称达到最高 99% 的成功率。v0.2 则直接支持 XSquare Turtle2 和 Franka Arm 两款真实机器人平台，提供了从数据采集、策略训练到真机部署的完整工作流。这一演进使 RLinf 从研究工具向工业级部署平台迈出了关键一步。

- **从单智能体到多智能体与智能体强化学习：** v0.1 主要支持单智能体的推理和具身任务。v0.2 引入了原生多智能体训练支持，包括可扩展的多智能体强化学习算法和统一数据接口，并能够复现 WideSeek-R1 等复杂解决方案。同时，v0.2 还扩展了智能体强化学习场景，支持了 rStar2 和 Search-R1 等新方法，使框架覆盖了更广泛的 AI 训练范式。

- **世界模型作为新仿真范式：** v0.2 引入了 OpenSora、Wan、WoVR 等世界模型作为强化学习训练的仿真器。这一创新允许策略在由生成模型“想象”出的轨迹上进行优化，理论上可以适配任何环境，同时保持一致的接口。这为 sim-to-real 和低成本策略迭代提供了新的可能性，是产品差异化的重要方向。

- **训练基础设施的深度优化与生态扩展：** v0.1 已具备 Megatron、FSDP 等训练后端和自动调度能力。v0.2 在此基础上增加了原生异步训练、CUDA Graph、torch.compile、环境卸载、FSDP 路径优化等性能改进，并支持了 FUSCO 通信库以加速 MoE 训练。同时，v0.2 还增加了对 NPU、AMD GPU 的支持，并提供了 PyPI 安装方式，降低了部署门槛。

## 版本演进解读

### v0.2 (2026-03-26)

- **核心能力升级：** 新增对 XSquare Turtle2 双臂机器人和 Franka Arm 的真实世界强化学习支持，提供从数据采集到策略训练的完整工作流。同时，引入 OpenSora、Wan、WoVR 等世界模型作为仿真器，允许在生成轨迹上进行策略优化。新增原生多智能体训练支持，可复现 WideSeek-R1 等复杂方案。新增 VLM 监督微调（SFT）能力，在 Robo2VLM 数据集上达到约 95% 的复现精度。

- **生态与算法扩展：** 新增对 Dexbotic 模型、RoboTwin 2.0 基准测试（支持 46 个任务）、CALVIN 基准测试、RoboCasa 基准测试的支持。新增 SAC-Flow、DSRL（Diffusion Steering via Reinforcement Learning）等算法。改进了对 IsaacLab 和 gr00t 模型的支持。新增对 Qwen3-VL 等 VLM 模型的 SFT 支持。

- **基础设施与性能优化：** 引入原生异步 PPO 训练，作为一等公民能力。新增 CUDA Graph、torch.compile、环境卸载、FSDP 路径优化等运行时性能优化。重构了数据收集和回放缓冲区管道，增强了缓冲区预加载、更新和检查点处理。新增对 FUSCO 通信库的支持，提升 MoE 训练中的 All-to-All 通信性能。新增对 NPU 和 AMD GPU 的支持。提供 PyPI 安装方式。

- **兼容性与迁移注意：** 源材料未明确描述破坏性变更。但 v0.2 重构了 `init_worker` 和权重同步机制，移除了 `EnvManager` 并添加了 `RecordVideo` 包装器，重构了 FSDP 精度处理（仅支持 fp16 和 bf16）。用户升级时应参考文档中的示例配置和 API 变更。

### v0.1 (2025-12-17)

- **首次公开发布：** 作为 RLinf 的第一个公开版本，v0.1 建立了基于 Worker、Scheduler、Channel 三层架构的系统设计，支持 GPU、NPU、CPU 异构资源管理。核心能力包括 GRPO、PPO、DAPO、REINFORCE++ 等强化学习算法，以及 Megatron 和 FSDP 训练后端。

- **具身智能验证：** 支持 ManiSkill、LIBERO、MetaWorld、CALVIN、IsaacLab、BEHAVIOR-1K 等主流仿真器，以及 OpenVLA、OpenVLA-OFT、π₀、π₀.₅、GR00T 等 VLA 模型。宣称在多个基准测试上达到最高 99% 的成功率，训练吞吐量相比现有框架提升最高 143.4%。

- **推理与智能体能力：** 在 AIME 24、AIME 25、GPQA-Diamond 等推理基准上达到领先水平。支持 1.5B 和 7B 模型的在线强化学习，并引入首个开源 1.5B 在线强化学习智能体，代码补全准确率提升 50% 以上。支持 SGLang、vLLM、HuggingFace 等回滚后端，以及自动调度和动态组件扩缩容。

## 采用与规划提示

- **建议优先评估 v0.2 的真实世界强化学习能力。** 如果团队有 XSquare Turtle2 或 Franka Arm 等真实机器人平台，v0.2 提供了从零开始训练 CNN 策略的完整工作流，包括数据采集、SAC 训练和部署。对于没有真实机器人的团队，世界模型（OpenSora 等）提供了一种低成本进行闭环策略优化的替代方案。

- **多智能体场景的用户应关注 v0.2 的原生多智能体支持。** 该功能降低了多智能体任务的开发门槛，并提供了 WideSeek-R1 等可复现的先进方案。如果团队正在探索多智能体强化学习或智能体搜索（如 Search-R1），v0.2 是合适的起点。

- **迁移成本需谨慎评估。** v0.2 的改动量巨大，涉及数据层、训练后端、组件接口等多个方面的重构。虽然源材料未明确列出破坏性变更，但建议用户在升级前仔细阅读 v0.2 的文档，特别是示例配置和 API 参考。对于生产环境，建议先在测试环境中验证现有工作流的兼容性。

- **产品路线图信号：** v0.2 明确聚焦于“真实世界强化学习”和“多智能体强化学习”两大方向。未来可能继续深化 sim-to-real 和 co-training 工作流，并扩展更多真实机器人平台的支持。同时，世界模型作为仿真器的引入，暗示了产品可能向“无需真实机器人即可进行策略优化”的方向演进。建议关注后续版本对更多机器人平台和世界模型的扩展。
