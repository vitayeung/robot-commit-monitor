# RLinf/RLinf Release Roadmap

- 仓库: `RLinf/RLinf`
- 统计窗口: 最近一年
- 最新版本: v0.2 (2026-03-26 23:06:12 CST)
- 纳入统计的最早版本: v0.1 (2025-12-17 20:01:25 CST)
- 版本概况: 最近一年共 2 个版本，其中正式版 2 个、预发布版 0 个
- 详细证据索引: `RLinf_RLinf_release_roadmap_reference.md`

## 核心判断

- **RLinf 从 v0.1 到 v0.2 完成了从“可扩展的强化学习后训练框架”到“面向具身智能与多智能体强化学习的生产级基础设施”的跃迁。** v0.1 验证了框架在仿真环境（ManiSkill、LIBERO 等）和推理/智能体场景下的基础能力与性能优势；v0.2 则大幅扩展了真实机器人平台支持、世界模型作为仿真器、多智能体训练等核心能力，产品边界显著拓宽。

- **v0.2 的核心战略方向是“真实世界强化学习”与“多智能体强化学习”。** 新增了对 XSquare Turtle2 双臂机器人和 Franka 机械臂的真实机器人训练支持，并引入了 OpenSora、Wan、WoVR 等世界模型作为仿真器，打通了 Sim-to-Real 和 Real2Sim2Real 的训练闭环。同时，原生多智能体训练支持使 RLinf 能够复现 WideSeek-R1 等复杂多智能体解决方案。

- **v0.2 在训练基础设施层面进行了大量优化，以支撑高吞吐、大规模训练。** 包括原生异步训练（Async PPO）、CUDA Graph、torch.compile、环境卸载（env offload）、FSDP 路径优化、以及基于 FUSCO 的 MoE 通信加速。这些改进直接提升了训练效率和可扩展性，对生产级部署至关重要。

- **v0.1 作为首个公开版本，已经展示了强大的系统级设计（Worker/Scheduler/Channel 三层抽象）和显著的性能优势（最高 143.4% 的训练加速）。** 该版本奠定了框架的架构基础，并验证了在具身、推理和智能体三大场景下的有效性，为 v0.2 的扩展提供了坚实底座。

## 产品演进主线

- **从仿真验证到真实世界部署的跨越。** v0.1 主要聚焦于 ManiSkill、LIBERO、MetaWorld、CALVIN 等仿真环境中的强化学习训练，验证了框架与多种 VLA 模型（OpenVLA、π₀、GR00T 等）的兼容性和性能。v0.2 则直接支持 XSquare Turtle2 和 Franka 机械臂的真实机器人训练，并引入了世界模型（OpenSora、Wan、WoVR）作为仿真器，实现了 Real2Sim2Real 和 Sim-Real 协同训练。这一演进意味着 RLinf 从研究验证阶段进入了真实场景落地阶段。

- **从单智能体到多智能体强化学习的扩展。** v0.1 主要支持单智能体的 PPO/GRPO 等算法。v0.2 引入了原生多智能体训练支持，包括可扩展的多智能体强化学习算法和统一数据接口，并能够复现 WideSeek-R1 这样的复杂多智能体解决方案。这使 RLinf 能够覆盖更广泛的协作与竞争场景，如多机器人协作、多智能体对话系统等。

- **训练基础设施从“可用”到“高效”的升级。** v0.1 已经具备自动调度、动态扩缩容、多后端（Megatron/FSDP/SGLang/vLLM）支持等系统级能力。v0.2 在此基础上增加了原生异步训练、CUDA Graph、torch.compile、环境卸载、FSDP 路径优化、FUSCO 通信库支持等性能优化，并重构了数据收集和回放缓冲区（Replay Buffer）架构。这些改进直接提升了训练吞吐量和资源利用率，对大规模训练场景至关重要。

- **模型与算法生态的显著扩展。** v0.1 支持 OpenVLA、π₀、GR00T、Qwen2.5 系列等模型。v0.2 新增了对 Dexbotic 模型、openpi 模型族、RoboTwin 2.0 的支持，并引入了 SAC-Flow、DSRL（Diffusion Steering via Reinforcement Learning）、VLM 监督微调（SFT）等新算法。同时，新增了 CALVIN、RoboCasa 等基准测试支持，以及 Robo2VLM 数据集的 SFT 验证。生态的扩展使 RLinf 能够覆盖更广泛的研究和应用需求。

## 版本演进解读

### v0.2（2026-03-26）

- **真实世界强化学习成为核心能力。** 新增对 XSquare Turtle2 双臂机器人和 Franka 机械臂的真实机器人训练支持，支持 SAC、Cross-Q、RLPD 等算法，并提供完整的 Docker 镜像和安装指南。这意味着用户可以直接在真实机器人上运行强化学习训练，而不仅限于仿真环境。

- **世界模型作为仿真器引入。** 支持 OpenSora、Wan、WoVR 三种世界模型作为强化学习训练的仿真环境，能够生成“想象”的轨迹来优化 VLA 策略。这为 Sim-to-Real 和 Real2Sim2Real 训练提供了新的技术路径，降低了真实机器人训练的成本和风险。

- **原生多智能体训练支持。** 引入了可扩展的多智能体强化学习算法和统一数据接口，能够复现 WideSeek-R1 等复杂多智能体解决方案。同时，PPO 扩展到了推理任务场景（Reasoning PPO），并支持了 rStar2 和 Search-R1 等智能体强化学习方案。

- **训练基础设施全面升级。** 新增原生异步训练（Async PPO）支持，引入 CUDA Graph、torch.compile、环境卸载、FSDP 路径优化等性能优化。重构了数据收集和回放缓冲区架构，增强了缓冲区预加载、更新和检查点处理能力。这些改进显著提升了高吞吐训练效率。

- **模型与算法生态大幅扩展。** 新增对 Dexbotic 模型、openpi 模型族、RoboTwin 2.0 的支持，引入 SAC-Flow、DSRL、VLM SFT 等新算法。新增 CALVIN、RoboCasa 等基准测试支持，并验证了 Robo2VLM 数据集的 SFT 效果（约 95% 的复现准确率）。同时，Megatron 后端新增 FUSCO 通信库支持，提升了 MoE 训练和推理的 All-to-All 通信性能。

- **兼容性与迁移说明。** 提供的来源未明确描述破坏性变更。FSDP 精度处理被重构为仅支持 fp16 和 bf16，但保留了向后兼容性。文档被重新组织，示例被分类为具身、智能体和系统级优化三类。

### v0.1（2025-12-17）

- **首个公开版本，奠定了框架的架构基础。** 引入了 Worker/Scheduler/Channel 三层系统抽象，支持 GPU、NPU、CPU 异构资源管理，以及自动 GPU 资源调度和动态组件扩缩容。Channel 提供了自适应高性能通信，自动选择最优通信后端（零拷贝 cudaIPC、NCCL、Gloo 等）。

- **在具身强化学习场景验证了显著性能优势。** 支持 ManiSkill、LIBERO、MetaWorld、CALVIN、IsaacLab、BEHAVIOR-1K 等主流仿真器，以及 OpenVLA、π₀、GR00T 等 VLA 模型。在多个基准测试上达到最高 99% 的成功率，训练吞吐量比现有框架最高提升 143.4%（2.434 倍），并支持灵活分配、解耦和混合执行模式。

- **在推理和智能体场景展示了强大能力。** 使用 1.5B 和 7B 模型在 AIME 24、AIME 25、GPQA-Diamond 等基准测试上达到最先进结果。通过流水线并行（20%+ 加速）和自动调度（30%+ 加速）显著提升效率。引入了首个开源 1.5B 在线强化学习智能体，代码补全准确率提升 50%+，超越 32B 规模模型。

- **支持多种算法和训练后端。** 支持 GRPO、PPO、DAPO、REINFORCE++ 等算法，以及 Megatron、FSDP 训练后端和 SGLang、vLLM、HuggingFace 推理后端。提供了统一的算法、环境和模型接口。

## 采用与规划提示

- **v0.2 适合已具备真实机器人硬件或计划进行 Sim-to-Real 研究的团队采用。** 新增的 XSquare Turtle2 和 Franka 真实机器人支持，以及世界模型作为仿真器的能力，使 RLinf 成为真实世界强化学习研究的首选框架之一。建议团队评估自身硬件兼容性，并参考官方 Docker 镜像和安装指南进行部署。

- **多智能体强化学习支持为协作机器人、多智能体对话等场景打开了新空间。** 如果团队正在探索多机器人协作、多智能体推理或复杂任务分解等方向，v0.2 的原生多智能体支持（包括 WideSeek-R1 的复现）提供了开箱即用的解决方案。建议从提供的示例配置入手，评估多智能体训练的工作流和数据接口是否满足需求。

- **训练基础设施的升级降低了大规模训练的门槛。** 异步训练、CUDA Graph、环境卸载等优化直接提升了训练吞吐量，对需要大规模并行训练的团队尤为重要。建议团队在规划训练集群时，充分利用这些优化特性，并关注 FUSCO 通信库对 MoE 模型的加速效果。

- **生态扩展方向明确，建议关注后续对更多机器人平台和算法的支持。** v0.2 新增了对 Dexbotic、RoboTwin 2.0、CALVIN、RoboCasa 等的支持，并引入了 SAC-Flow、DSRL、VLM SFT 等新算法。这表明 RLinf 正在快速扩展其生态覆盖范围。建议团队关注官方文档和 HuggingFace 模型库的更新，以获取最新的模型权重和示例配置。
